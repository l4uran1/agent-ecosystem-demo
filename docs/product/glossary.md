# Glossary

Domain terms with the meaning they have in this product, in alphabetical order.

| Term | Meaning |
| --- | --- |
| Cents | Every amount is an integer number of the currency's minor unit (cents, pence). Never a float. |
| Confirmation email | The email notifier sends when an order is created. Not a receipt: the invoice is. |
| Corrective invoice | A new invoice that cancels or fixes an issued one. Issued invoices are never edited. |
| Exchange rate | EUR per one unit of the order's currency, fixed when the order is created. |
| Invoice | The legal record of a sale, issued by invoicing. One per order, numbered by year and sequence, e.g. `INV-2026-0001`. |
| Order | What a customer buys in one checkout. Prices include VAT. |
| SKU | The code of a product, e.g. `ETHIOPIA-250G`. |
